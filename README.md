# For Noran

A small React/Vite birthday experience with animated scenes, a photo gallery, and background music.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run lint
npm run build
npm run preview
```

The production output is written to `dist/` and can be deployed to Vercel with the default Vite settings. The project does not currently require environment variables.
